# ParusSmart Display: Умный сенсорный пульт для Home Assistant на Guition 4848S040

## 🌟 Описание проекта

**ParusSmart Display** — это проект локальной сенсорной панели управления умным домом на базе **Guition 4848S040 (ESP32-S3)** и библиотеки **LVGL**. Устройство подключается к Home Assistant через нативный API ESPHome, обеспечивая мгновенный отклик, красивый интерфейс и полную автономность без облачных сервисов.

Панель оснащена большим 480x480 IPS-экраном и емкостным тачскрин-контроллером. Интерфейс спроектирован для повседневного использования: управление освещением, климатом, воротами, энергомониторинг и многое другое.

Проект позволяет:

- управлять всеми ключевыми узлами дома (свет, бойлеры, кондиционеры, вентиляция, краны) с сенсорного экрана;
- визуализировать энергопотребление (солнечная генерация, сеть, АКБ) в реальном времени;
- получать уведомления о тревогах (протечки, дым, газ) и статусе устройств;
- использовать систему пресетов и сценариев (включая управление списком покупок и медиаплеерами);
- работать полностью локально, используя всю мощь ESPHome для отрисовки графики и обработки касаний.

## 🔑 Ключевые возможности

### 🖥️ Пользовательский интерфейс (LVGL)

- **Многостраничная навигация**: Главный экран, Устройства, Свет, Энергия, Климат, Медиа, Настройки.
- **Адаптивная верстка**: Плитки и кнопки с плавной анимацией (включая анимацию вращения вентиляторов и зарядки АКБ).
- **Кастомные шрифты**: Использование иконок Parus, MDI и шрифтов Nunito для идеального отображения кириллицы и пиктограмм.
- **Управление подсветкой**: Плавная регулировка яркости экрана и автоматическое отключение по таймауту (с возможностью блокировки от детей).

### 💡 Управление устройствами

- **Освещение**: Управление группами света (гостиная, кухня, с/у, уличные фонари) с обратной связью по цвету и яркости.
- **Климат**: Контроль кондиционеров (Toshiba, Airwell), управление бойлерами (подвал, 2 этаж, 31, 34), настройка ночных/дневных режимов.
- **Вентиляция**: Управление вытяжками и клапанами (спортзал, подвал) с индикацией положения.
- **Безопасность**: Управление воротами, гаражом, кранами воды и газа с контролем состояния.

### ⚡ Энергомониторинг

- Отображение солнечной генерации (PV), потребления из сети (Grid) и заряда батареи (Battery).
- Кольцевая диаграмма распределения энергии между домом, сетью и АКБ.
- История расхода воды и атмосферного давления.

### 📱 Интеграция с Home Assistant

- **Прямое чтение и запись** сущностей через API.
- **Уведомления**: Всплывающие окна для списка покупок (Todo) и уведомлений.
- **Медиаплееры**: Управление Яндекс.Станциями (Midi, Lite) с синхронизацией треков и громкости.

## 🛠 Компоненты и аппаратура

### Основные компоненты

- **Микроконтроллер**: ESP32-S3 (N16R8) с поддержкой PSRAM (Octal SPI).
- **Дисплей**: Guition 4848S040 480x480 IPS (ST7701S).
- **Тачскрин**: Емкостный сенсор GT911 (I2C).
- **Подсветка**: Управление через ШИМ (LEDC).

### Программные зависимости

- **ESPHome**: Версия 2026.9.1+ (с поддержкой LVGL 9.x и виджетов).
- **Home Assistant**: Интеграция через нативный API.
- **Компоненты**: `st7701s`, `gt911`, `lvgl` (виджеты, анимации, градиенты).

## 📋 Установка и настройка

### 1. Подготовка оборудования
Прошейте дисплей прошивкой ESPHome (через OTA или USB).

### 2. Структура проекта
Проект использует модульную структуру с подключением пакетов (packages). Убедитесь, что файлы виджетов и шаблонов находятся в правильных директориях:

```yaml
packages:
  standart: !include attach/packages/standart.yaml
  media_player: !include media_player/media_player.yaml
  air_conditioner: !include air_conditioner/air_conditioner_config.yaml
  boiler: !include boiler/boiler_config.yaml
  alarm: !include alarm/alarm_config.yaml
```
### 3. Интеграция с Home Assistant

- Соберите и прошейте ESP32-S3.
- После подключения к Wi-Fi устройство автоматически появится в HA.
- Добавьте все необходимые сущности (сенсоры, переключатели, селекторы) на панель.

## ⚠️ Известные ограничения и решения

В процессе эксплуатации были выявлены ограничения архитектуры Xtensa (ESP32-S3), которые потребовали оптимизации кода:

- **Ошибка `l32r: literal target out of range`**: Возникает при переполнении функции `setup()` (генерируется компилятором). Решение: замена виджетов `obj` на плоские `label` с фоном, уменьшение количества действий и лямбд, оптимизация триггеров.
- **Артефакты экрана**: Решаются настройкой параметров дисплея в коде.
